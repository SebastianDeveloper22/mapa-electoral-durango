📍 Módulo PP — Marcadores

Cómo se crea un marcador (flujo)

1. Clic derecho en el mapa → MapContainer.jsx:198 llama a openModalNuevo(coords)
2. ObraModal.jsx se abre con selector de capa
3. Al guardar: PP → obrasService.createObra() → colección obras. Otros → marcadoresService.createMarcador() → marcadores_rural, marcadores_top100 o marcadores_generales
4. MapPage.jsx llama handleReload() que incrementa reloadKey
5. PinLayer.jsx re-carga todos los pines

🛡️ Admin y Auth

Roles del sistema

RolPuede hacer
lectorSolo ver datos. No puede crear, editar ni borrar nada.
editorCRUD de obras, marcadores, elecciones, casillas, resultados.
adminTodo lo anterior + gestionar roles de usuarios + ver papelera.
En dispositivos móviles (ancho ≤ 768px), los roles editor y admin se degradan automáticamente a lector. Definido en hooks/useAuth.js.

Opciones de rol en AdminPanel

Definidas en AdminPanel.jsx línea 10:

CONFIGRoles disponibles para asignarAdminPanel.jsx:10
ROLES_OPCIONES = ["lector", "editor", "admin"]

Cómo se carga el rol de un usuario

Al hacer login, useAuth.js busca en Firestore el documento roles/{uid} y lee el campo rol. Si no existe el documento, el usuario queda bloqueado (sin rol = sin acceso a escritura). El primer admin debe crearse manualmente en Firebase Console.

Cómo agregar un usuario nuevo

1. Abre la app como admin → botón 🛡️ Admin
2. Escribe el email del usuario y selecciona el rol
3. El usuario debe existir previamente en Firebase Authentication (puede registrarse o ser creado desde Firebase Console)

Variables de entorno Firebase

Guardadas en .env (nunca subir a git — está en .gitignore):

VariableDescripción
VITE_FIREBASE_API_KEYAPI Key del proyecto
VITE_FIREBASE_AUTH_DOMAINDominio de autenticación
VITE_FIREBASE_PROJECT_IDID del proyecto Firebase
VITE_FIREBASE_STORAGE_BUCKETBucket de Storage para imágenes
VITE_FIREBASE_MESSAGING_SENDER_IDID del remitente
VITE_FIREBASE_APP_IDID de la app web
Si clonas el proyecto en otra máquina, necesitas crear el archivo .env manualmente copiando .env.example y poniendo los valores reales desde Firebase Console → Configuración del proyecto.
